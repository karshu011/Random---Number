# Random---Number
# 🎲 Random Number Generator

A simple and user-friendly Random Number Generator developed using HTML, CSS, and JavaScript. This application generates random numbers within a specified range.

## 🚀 Features

- 🔢 Generate random numbers
- 🎯 Set minimum and maximum number values
- 🔄 Generate a new random number anytime
- ⚡ Instant number generation
- 📱 Simple and responsive design
- 🎨 User-friendly interface
- ❌ Input validation for invalid values

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Random-Number-Generator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter the minimum and maximum values.

5. Click the Generate button to get a random number.
